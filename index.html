FAQ

1. What is the current development status of MSX?

MSX is a community project built on OpenToonz. It’s not a standalone program — everyone can create and customize their own projects.

2. Can I use MSX right now?

Yes. Any user can start building custom projects on OpenToonz. There’s no official release, as it depends on what each user creates.

3. Is MSX a standalone program?

No. MSX is entirely dependent on OpenToonz and on the users themselves if they wish to modify the program.
